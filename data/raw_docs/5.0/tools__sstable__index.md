# SSTable Tools

This section describes the functionality of the various `sstable` tools.

Cassandra must be stopped before these tools are executed, or unexpected
results will occur. Note: the scripts do not verify that Cassandra is
stopped.

* [sstabledump](sstabledump.html)
* [sstableexpiredblockers](sstableexpiredblockers.html)
* [sstablelevelreset](sstablelevelreset.html)
* [sstableloader](sstableloader.html)
* [sstablemetadata](sstablemetadata.html)
* [sstableofflinerelevel](sstableofflinerelevel.html)
* [sstablepartitions](sstablepartitions.html)
* [sstablerepairdset](sstablerepairedset.html)
* [sstablescrub](sstablescrub.html)
* [sstablesplit](sstablesplit.html)
